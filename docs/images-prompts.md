# QuestHabit — Image Sizing Guide

> **Key rule:** Images displayed full-screen with `contentFit="cover"` should be portrait
> or square to avoid excessive side-cropping on phone screens (phones are ~9:19.5 portrait).
> Images displayed as contained elements (inside a card or section) can be landscape.
